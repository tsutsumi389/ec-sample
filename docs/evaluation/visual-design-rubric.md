# ビジュアルデザイン重視 UI/UX ルーブリック（100点満点 / 合格ライン 90点）

対象: 実際にブラウザでレンダリングされた画面。**ビジュアル的なデザイン性を最重視**し、配点の 65% を視覚表現に割く。
`docs/evaluation/uiux-visual.md`（実装網羅性ベース・合格80点）とは別軸の、**表現の質**を測るための基準。

## 撮影・確認条件

| 項目 | 条件 |
|---|---|
| ビューポート | デスクトップ 1440px / モバイル 390px（必要に応じ 768px） |
| ページ | トップ、商品一覧、商品詳細、カート、ログイン |
| 撮影 | `fullPage`, `deviceScaleFactor: 2`, `locale: ja-JP`, ネットワークアイドル後 1.2 秒待機 |

## 採点ルール

1. 各項目は 0〜配点で採点する。小数点以下は 0.5 刻みまで許容。
2. **根拠必須**。加点・減点にはスクリーンショットのファイル名と、該当箇所を `path/to/file.tsx:123` 形式で必ず引用する。根拠のない点は 0 点として扱う。
3. **満点は「その分野のプロダクトとして商用水準」を意味する**。「実装されている」だけでは配点の 60% が上限。「破綻していない」は 70% 止まり。**80% を超えるには意図の見える設計判断が視認できること**。
4. **デスクトップのみ / モバイルのみ良好** の場合、その項目は配点の 50% を上限とする。
5. **ビジュアル項目（A）のフロア条件**: A1〜A6 のいずれか 1 つでも配点の 80% 未満の場合、総合点が 90 点以上でも **不合格**とする。UX で点を稼いで視覚表現の弱さを相殺することを禁じる。
6. 3 名以上の独立した採点者で採点し、**中央値**を採用する。採点者間で 15 点以上の乖離がある項目は再採点する。

## A. ビジュアルデザイン（65点）

### A1. タイポグラフィ体系（12点）

| 配点帯 | 判定基準 |
|---|---|
| 0-4 | 単一フォント・単一ウェイト中心。見出しと本文がサイズ差だけで区別されている |
| 5-8 | 型階層（display/h1/h2/body/caption）が定義され一貫適用。行間・字間が和文向けに調整されている |
| 9-12 | 見出し用の表情あるフェイス（または明確なウェイト・字間設計）があり、数値・価格に等幅/タブular数字が効いている。和文の**約物・改行位置**（`text-wrap: balance` / `word-break` 等）まで配慮され、長い商品名でもレイアウトが崩れない |

### A2. カラー & マテリアル（12点）

| 配点帯 | 判定基準 |
|---|---|
| 0-4 | 汎用グレー（`gray-50`/`gray-200`）とブランド色1色の素朴な構成。面の質感が一様 |
| 5-8 | ニュートラルが世界観に合わせて調色され（暖色寄せ等）、サーフェス階層（背景/カード/浮上要素）が明度で区別される |
| 9-12 | セマンティックなカラートークンが定義され、影・境界・背景の3手段を**使い分けて**深度を作っている。セール価格・在庫僅少などのアクセント色が体系の中に位置づけられ、単発の色が存在しない |

### A3. レイアウト & 余白のリズム（12点）

| 配点帯 | 判定基準 |
|---|---|
| 0-4 | 全セクションが同一の余白・同一の横幅。単調な縦積み |
| 5-8 | スペーシングスケールに沿った余白。セクション間に強弱があり、コンテンツ幅が用途で使い分けられている |
| 9-12 | 視線誘導が設計されている（フルブリード帯・非対称グリッド・アシンメトリな比率等）。**スクロールしたときにリズムを感じる**。1440px でも 390px でも間延び／窮屈にならない |

### A4. コンポーネントの造形精度（10点）

| 配点帯 | 判定基準 |
|---|---|
| 0-3 | 角丸・ボーダー・パディングが箇所ごとにばらつく |
| 4-7 | ボタン・カード・バッジ・フォームの造形が統一され、サイズバリエーションが体系化されている |
| 8-10 | 角丸の入れ子（外側 > 内側）、ボーダー幅、アイコンの光学サイズまで揃っている。**カード内の情報密度が整理され、要素同士が競合していない** |

### A5. ブランド表現・世界観（10点）

| 配点帯 | 判定基準 |
|---|---|
| 0-3 | 汎用ECテンプレートに見える。ブランド名を差し替えても違和感がない |
| 4-7 | ロゴ・配色・コピーに一貫性があり、ブランドの人格が読み取れる |
| 8-10 | 「日々の暮らしの道具店」という世界観がヒーロー・セクション見出し・余白・写真の扱いから伝わる。**記憶に残る画面が1つ以上ある**。装飾が世界観に奉仕しており、単なる飾りではない |

### A6. モーション & マイクロインタラクション（9点）

| 配点帯 | 判定基準 |
|---|---|
| 0-3 | hover で色が変わるだけ。状態遷移が瞬間的 |
| 4-6 | hover/active/focus に一貫したトランジションがあり、スケルトンがレイアウトと一致している |
| 7-9 | 意味のある動き（カード浮上・画像のパララックス的スケール・段階的な出現）が**統一されたイージングと duration トークン**で実装され、`prefers-reduced-motion` を尊重している |

## B. UX（35点）

### B1. 情報アーキテクチャ・ナビゲーション（8点）

現在地表示、パンくず、戻り導線、ヘッダーの情報整理、モバイルナビの操作性。
- 0-3: 主要導線は辿れるが現在地が不明 / 4-6: アクティブ表示とパンくずがある / 7-8: 階層が視覚的に自明で、深い階層からでも迷わない

### B2. 購買導線の摩擦（9点）

検索 → 一覧 → 詳細 → カート → 注文の各ステップ。
- 0-3: 到達可能 / 4-6: 各画面で CTA が最も目立つ / 7-9: 次の行動が画面を見た瞬間に分かり、カート追加のフィードバックが即座かつ非破壊的。価格・在庫・送料の情報が判断に必要な位置にある

### B3. 状態表現（6点）

loading / empty / error / disabled / 0件。
- 0-2: 存在する / 3-4: スケルトンと空状態がデザインされている / 5-6: 全状態が世界観に沿ってデザインされ、エラーから復帰する導線がある

### B4. レスポンシブ（7点）

390 / 768 / 1440。
- 0-2: 崩れない / 3-5: 各幅で最適な列数・余白 / 6-7: 幅ごとに情報の優先順位が組み替わっている（単なる縮小ではない）

### B5. アクセシビリティ（5点）

コントラスト比 (WCAG AA)、フォーカスリング、タップ領域 44px、`alt`、セマンティクス。
- 0-2: フォーカスリングがある / 3-4: 主要テキストが AA を満たす / 5: 全インタラクティブ要素が AA + 44px + 適切なラベルを満たす
