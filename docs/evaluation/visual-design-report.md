## 4. 頭打ちの原因

並列4エリアで修正する方式が限界に達した。各エリアは自分の指摘を潰す一方で、**横断的な体系の一貫性を削る**。

実例: R4 で「合わせておすすめ」の残り列を埋める `MORE` 札に `col-span-2` を付けた結果、
`md:grid-cols-3`（768px）で 490×490px の L 字の空白が発生し、B4 が 5.75 → 5.0 に低下した。

残る失点は個別の破綻ではなく**体系レベルの設計判断**に移っている。これらは1人の作者が
順に決めるべき性質のもので、並列パッチでは直すそばから別の不整合が生まれる。

## 5. 残課題（体系レベル・優先順）

### 5-1. 「買う理由」と「買えない」が同じ色を共有している（A2 / A4）

`ProductPrice.tsx:49`（%OFF）、`StockLabel.tsx:31`（残りN点）、`lib/productStatus.ts:36`（販売停止中）が
すべて `variant='accent'` で、しかも `ProductCard` の同じ左下1席に出る。
「21%OFF」と「販売停止中」が同一の橙のピルとして並び、文字を読むまで区別できない。
一方で在庫切れは `neutral`、近日発売は `brand` なので、5状態が誤った軸でグルーピングされている。

**方針**: 色を「買える／買えない」の軸で割る。`suspended` を `neutral` に寄せ、
accent は %OFF と 残りN点（＝買う理由）だけに残す。

### 5-2. 見出しの階層が1段しかない（A1）

ページ直下のセクション見出しと、その内部の従属ブロック見出しが、同寸・同ウェイト・同装飾
（緑の縦罫＋明朝＋短い横罫）で組まれている。商品詳細では6つの見出しが全部同じ階層に見える。

**方針**: `SectionHead` に `level='section' | 'block'` を追加し、従属ブロックは
`text-h3`・縦罫なし・eyebrow のみにする。

### 5-3. 線画の墨の丈が揃っていない（A4 / A5）

`BrandMotifs.tsx` の各モチーフは viewBox 120×120 に正規化され接地線 y=108 も守られているが、
**墨（描画されたパス）の高さ**が 64〜107px と最大1.67倍ばらつく。ケトルだけが常に最小（鉢の60%）で、
同じ棚罫の上に並ぶため「1つだけ縮小し忘れた」ように見える。この3点セットは
署名帯・フッター・ログイン左パネル・空状態・扉に反復するため、影響範囲が広い。

**方針**: 各パスを、墨のバウンディングボックスが高さ96（y=12..108）を占めるよう描き直す。

### 5-4. 「取得に失敗した」状態が3造形ある（B3 / A4）**← critical**

- `/products`・`/`・`/categories` = `ErrorNotice`（線画→棚の罫→明朝見出し→復帰ボタン、中央寄せ）
- `/cart` = `critical-50` のベタ塗り全幅箱（`app/cart/page.tsx:334-348`）
- `/orders` = 素の赤い1行のみ、**復帰導線なし**（`app/orders/page.tsx:140-144`）

`/orders` は行き止まりになり、作りかけに見える。

**方針**: 全箇所を `ErrorNotice` に寄せる。

### 5-5. スケルトンが実レイアウトと別の判型を予約している（B3 / A6）

- カート: 骨格は版面いっぱい1カラム、実物は 7/12＋5/12 の2カラム（`app/cart/page.tsx:350-357`）
- 表紙: 骨格は 500×500 の正方形、実物は 520×402 の 4:3（`HomeSections.tsx:115-119`）

読み込み完了の瞬間にサイト最大の要素が飛ぶ。

### 5-6. レーンの造形が3本連続で同じ（A3 / A5）

`HomeSections.tsx:62-91` の `selectLanes()` の variant 割り当てが、コメントの意図
（「ranked を挟んで造形を交替させる」）どおりに機能していない。

## 6. 欠陥一覧（29件）

R4 時点の欠陥は critical 1 / major 19 / minor 9。全件の詳細（場所・原因ファイル:行・修正案）は
スクラッチパッドの `fixlist4.md` に記録した。上記5節に挙げていない主なものは以下。

- 390px でヒーロー画像が `object-cover` により上下で断ち切られ、湯気と接地影が消える（`HomeBillboard.tsx:141`）
- 扉の装飾線画が切りすぎで図案が判読不能な弧の断片になる（`PageMasthead.tsx:76`）
- 1行名と2行名が混在する行で、1行名のカードにのみ約40〜45px の空洞（`ProductCard.tsx:132`）
- カード価格行で「★ 5.0 (1件)」の閉じ括弧が右端で切れる（`ProductCard.tsx:164-174`）
- ページネーションでボタンの面が4種類に割れ、無効の「前へ」が有効な番号より強く見える（`Pagination.tsx:50-53`, `buttonStyles.ts:31`）
- ヘッダーの「検索」submit だけが `bg-sunken`＝disabled 専用に予約された面を使っている（`SearchBox.tsx:397`）
- 「合わせておすすめ」の MORE 札が深緑帯の上でほぼ透明になり、右半分が穴に見える（`ProductRecommendations.tsx:174`）
- ホームで同一の空状態ロックアップが 1,024px 離れて2回出る（`HomeSections.tsx:271-274` と `app/page.tsx:132-135`）
