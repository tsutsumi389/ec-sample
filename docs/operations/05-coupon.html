05クーポン運用

/admin/coupons でコードを発行し、購入者がカートで入力する。1 注文に使えるのは 1 枚だけで、割引は商品代金の小計にのみ効く（送料という概念自体が無い）。

5.1クーポンを発行する

  1. /admin/coupons の「新規作成」を押す
  2. クーポンコードを入力する。打つそばから自動的に大文字に変換される（照合は完全一致なので、小文字で配布したコードは使えない）
  3. 割引種別（％ / 円）と割引値を入れる
  4. 必要なら最低注文金額と有効期限を入れる。どちらも空でよい（空＝制限なし / 無期限）
  5. 「有効にする」にチェックが入っていることを確認して保存する。保存した瞬間から使える状態になる
  6. 一覧に行が増えたことを確認し、コードを配布する

5.2入力項目

項目必須意味と注意
クーポンコード必須購入者が打ち込む文字列。全クーポンで一意（重複すると「このクーポンコードは既に使用されています。」と出る）。入力時に大文字化される
割引種別必須％（定率） か 円（定額） の 2 択
割引値必須％なら割引率、円なら割引額。0 以上であること以外の制限は無い（100 を超える％も入力できてしまう）
最低注文金額任意（既定 0）小計がこの額未満だと使えない。0 なら制限なし
有効期限任意日時で指定する。空にすると無期限。入力した日時はそのままの時刻で失効する
有効にする—チェックを外すと即座に使えなくなる。クーポンを止める通常の手段はこれ

5.3割引額の計算規則

  • 対象は商品代金の小計（各商品の実売価格 × 数量の合計）
  • ％の場合、1 円未満は切り捨てられる。小計 1,055 円の 10% は 105 円（105.5 円ではない）
  • 定額の場合はその額をそのまま引く
  • いずれも割引額の上限は小計そのもの。小計を超える割引を設定しても、支払額がマイナスになることはなく 0 円で止まる
割引率に上限が無い

％に 100 以上を入れても保存でき、その場合常に全額無料のクーポンになる（割引額が小計で頭打ちになるため）。桁を打ち間違えても警告は出ない。保存後に一覧の「割引」列を必ず読み返すこと。

5.4購入者から見た使い方

  1. カートページの「クーポンをお持ちの方」という折りたたみパネルを開く。このパネルはログイン中にしか表示されない（未ログインのまま購入手続きに進む導線では使えない）
  2. コードを入力して適用を押すと、その場で検証され「クーポンを適用しました」と出る
  3. カートの数量を変えたり商品を消したりすると、自動で再検証される。最低注文金額を割ると「カート内容が変わったためクーポンを解除しました」と表示され、自動的に外れる
  4. 注文確定時にもう一度サーバー側で検証される。ここで無効なら注文そのものが失敗する
エラー文言の癖

存在しないコードと、無効化されたコードは同じ「無効なクーポンコードです。」になる。購入者から「使えない」と問い合わせが来たとき、コードの打ち間違いなのか運営が止めたのかは、管理画面の一覧を見て判断する。
また、最低注文金額に届かないときのメッセージは Minimum order amount is ... と英語のまま表示される。日本語化されているのは固定の文言だけで、金額が埋め込まれるこの文言は表に載っていないためである。

5.5クーポンを止める・終わらせる

やりたいこと操作結果
いますぐ使えなくする編集 →「有効にする」のチェックを外して保存即座に使えなくなる。一覧では「無効」バッジになる。あとで戻せる
期限で自然に終わらせる有効期限を設定しておくその日時を過ぎると使えなくなる
記録ごと消す一覧の「削除」クーポンが本当に消える。過去の注文に残ったコードの記録は壊れない（注文側は文字列として保持しているため）
期限切れのクーポンは一覧で「有効」のまま並ぶ

有効期限を過ぎても、is_active は自動では落ちない。一覧の状態列は「有効」バッジのままで、有効期限の列を目視しないと失効済みだと分からない。使えなくなっていること自体は保証されているので実害は無いが、「いま生きているクーポンはどれか」を一覧から一目で把握することはできない。定期的に棚卸しして、終わったものはチェックを外すか削除しておくと読みやすくなる。

5.6使用回数を制限できない

同じコードは、同じ人が何度でも使える

「先着 100 名」「お 1 人様 1 回」といった制限を設定する項目が無く、使用実績を記録する仕組みも無い。一度配ったコードは、止めるまで無制限に使われ続ける。運用としては次のいずれかで対処する。

  • 有効期限を短く切り、期間で絞る
  • 配布先ごとに別々のコードを発行し、使われたことを確認したら個別に無効化する
  • 大きな割引率のクーポンは、有効期限と最低注文金額を必ず併用する

なお「このクーポンが何回使われたか」を管理画面から知る手段も無い。過去の注文に記録されたクーポンコードを DB から数えるしかない（08 章）。

対象を絞ることもできない

特定の商品・カテゴリ・初回購入者だけに効かせる設定は無い。クーポンは常にカート全体の小計に対して効く。
